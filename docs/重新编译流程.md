# SanDaoPoker 重新编译流程

适用环境：Windows 10/11 + Visual Studio 2022（C++ 桌面开发）+ Git。
目标：从源码得到最新、干净、可运行的 SanDaoPoker.exe。

## 〇、环境前提（只装一次）

| 组件 | 说明 |
|---|---|
| Visual Studio 2022 Community | 安装时勾选“使用 C++ 的桌面开发”，自带 CMake 与 Ninja |
| Git for Windows | 提供 git 命令，构建本身不依赖 |

构建所需的 MSVC 环境由脚本自动定位，无需手工配置路径。如需查询 Visual Studio 安装位置，可执行：

```bat
"%ProgramFiles(x86)%\Microsoft Visual Studio\Installer\vswhere.exe" -latest -property installationPath
```

## 一、完整重新编译（保证 100% 最新）

适用场景：素材更新但 exe 陈旧、构建异常、需要确认版本为最新。

### 第 1 步：更新代码

在项目根目录执行：

```bat
git pull
```

### 第 2 步：删除旧构建目录

```bat
rmdir /s /q build
```

`build/` 内是上次链接时的素材快照；增量构建在代码未变时不会重新链接，素材会停留在旧版本。删除后重新构建，可保证 exe 与素材全部为新。

### 第 3 步：配置

方式一：双击 `tools\build_all.bat`，脚本自动定位 VS 环境并完成配置与编译。

方式二：在已加载 MSVC 环境的终端中手工执行。环境加载方式：开始菜单打开 **Developer Command Prompt for VS 2022**；或先调用 vcvars64.bat，其位置为 `<VS安装目录>\VC\Auxiliary\Build\vcvars64.bat`。

```bat
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTS=ON
```

- `-G Ninja`：使用 Ninja 构建（速度快）
- `-DCMAKE_BUILD_TYPE=Release`：发布构建（Debug 构建缺对应 DLL，不推荐）
- `-DBUILD_TESTS=ON`：同时生成单元测试（可省略，默认 OFF）
- 首次构建会自动解压 `third_party/SFML-2.6.1.zip`

### 第 4 步：编译

```bat
cmake --build build
```

日志出现 `Linking CXX executable SanDaoPoker.exe` 与 `Copying assets to output directory` 即为成功（全量约 1~2 分钟，增量数秒）。

### 第 5 步：运行与验证

```bat
bin\SanDaoPoker.exe
```

exe、SFML DLL、`assets/` 素材与 `game_data/` 存档集中在 `bin/` 目录；程序启动时自动以自身所在目录为工作目录，可从任意路径启动。
验证点：窗口标题为“SanDaoPoker - 炸金花三道”、主菜单有背景音乐、无报错弹窗。

## 二、日常增量编译

```bat
cmake --build build
```

素材（图片/音效/字体）变更后直接构建即可：构建时自动同步，日志显示 `Syncing assets to output directory` 及具体同步/清理的文件。

## 三、单元测试

```bat
build\test_hand_evaluator.exe
```

或 `ctest --test-dir build`（需配置时加 `-DBUILD_TESTS=ON`）。

## 四、一键构建脚本

`tools\build_all.bat` 已随仓库提供，双击即可完成“定位 VS 环境 → 配置 → 编译”全流程，可在任意目录运行。

## 五、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 缺少 sfml-xxx-d-2.dll | Debug 构建链接了调试库 | 使用 `-DCMAKE_BUILD_TYPE=Release`，或删除 build 重新配置 |
| 素材更新后画面仍旧 | 构建未执行素材同步 | 重新 `cmake --build build`；仍无效则删除 `bin/` 完整重建 |
| 修改 CMakeLists.txt 未生效 | 需要重新配置 | 重新执行第 3 步配置命令 |
| 编译报 cl.exe 找不到 | 未加载 MSVC 环境 | 使用 Developer Command Prompt 或 `tools\build_all.bat` |
| 首次编译耗时长 | 解压 SFML + 全量编译 | 正常现象，约 1~2 分钟 |
