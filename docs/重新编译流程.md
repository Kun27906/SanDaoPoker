# SanDaoPoker 重新编译完整流程

> 适用:Windows 11 + Visual Studio 2022(C++ 桌面开发) + Git
> 目的:任何时候从源码得到一份**最新、干净、可运行**的 SanDaoPoker.exe

## 一、完整重新编译(推荐:保证 100% 最新)

> 什么时候用:素材更新了但 exe 是旧的 / 构建出怪问题 / 想确认拿到的是最新版

### 第 1 步:确保代码最新

```bash
cd D:\C++\SanDaoPoker
git pull
```

### 第 2 步:删掉旧构建目录(关键!)

```bash
rmdir /s /q build
```

> 为什么必须删:`build/` 里的素材是**上次链接时**拷贝的旧快照;
> 增量构建在代码没变时不会重新链接,素材就永远是旧的。
> 删掉后重新构建 = exe 和素材全部重新生成,拿到 100% 最新。

### 第 3 步:配置(生成构建系统)

打开 **命令提示符(cmd)**,执行:

```bat
call "D:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTS=ON
```

- `vcvars64.bat` 加载 MSVC 编译环境(Ninja 需要能找到 cl.exe)
- `-G Ninja` 用 Ninja 构建(快)
- `-DCMAKE_BUILD_TYPE=Release` 发布版(默认即可,别用 Debug 会缺 DLL)
- `-DBUILD_TESTS=ON` 顺便生成单元测试(可省略,默认 OFF)
- 首次构建会自动解压 `third_party/SFML-2.6.1.zip`(看到 "正在自动解压" 是正常的)

### 第 4 步:编译

```bat
cmake --build build
```

看到 `Linking CXX executable SanDaoPoker.exe; Copying assets to output directory` 即成功。
(编译含 SFML 全量约 1~2 分钟,增量几秒)

### 第 5 步:运行与验证

```bat
bin\SanDaoPoker.exe
```

程序从 **bin/ 目录**运行(或双击 `D:\C++\SanDaoPoker\bin\SanDaoPoker.exe`),
exe + SFML DLL + assets/ 素材 + game_data/(账号存档) 全部集中在这个文件夹。
验证:窗口标题"SanDaoPoker - 炸金花三道"、主菜单有 BGM、无弹窗报错。

## 二、日常增量编译(代码小改时用)

```bat
call "D:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"
cmake --build build
```

> ⚠️ 若只改了**素材文件**(图片/音效/字体),增量编译不会更新 bin/assets——
> 删掉 `bin\SanDaoPoker.exe` 再 `cmake --build build`(强制重链触发素材重拷),或直接用"完整流程"。

## 四、可选:一键脚本(推荐)

把下面内容存为 `D:\C++\SanDaoPoker\build_all.bat`,以后双击即可完整重编:

```bat
@echo off
chcp 65001 >nul
cd /d D:\C++\SanDaoPoker
call "D:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTS=ON
cmake --build build
echo.
echo 构建完成! 运行 bin\SanDaoPoker.exe
pause
```

(该脚本放项目根目录,不入库的话加到 .gitignore;要入库也可以,放 tools/ 下)

## 五、常见问题(编译相关)

| 现象 | 原因 | 解决 |
|---|---|---|
| 弹出"找不到 sfml-xxx-d-2.dll" | 用了 Debug 构建(链接 Debug 库),但拷贝了 Release DLL | 构建时加 `-DCMAKE_BUILD_TYPE=Release`,或删 build 重来 |
| 素材更新了但画面还是旧的 | bin/assets 是旧快照 | 删 bin\SanDaoPoker.exe(或整个 bin/)后重新编译 |
| 改了 CMakeLists.txt 但没生效 | 需要重新配置 | 重新执行第 3 步的 cmake 配置命令 |
| 编译报 `cl.exe` 找不到 | 没加载 vcvars64 环境 | 先 `call vcvars64.bat` 再 cmake |
| 首次编译很久 | 在自动解压 SFML + 全量编译 | 正常,等 1~2 分钟 |
